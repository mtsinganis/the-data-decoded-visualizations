# Source snapshot and reproduction

Retrieved 2026-10-08. Chart inputs are the preserved CBS PDFs and spreadsheets in sources.csv. source_checksums.csv records SHA-256 checksums generated by analysis.R.

From the repository root:

```powershell
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' visuals/2026-10-israel-migration-balance/analysis.R
```

R requires the packages declared at the top of analysis.R. PDF extraction uses Python with pdfplumber; the default is the bundled Codex Python on this Windows machine. Set TDD_PYTHON to another compatible interpreter if needed. No live download is needed to regenerate the saved snapshot.

- extract_pdf.py matches Hebrew component anchors in the extracted first page and exports latest_period.csv. It stops on missing or duplicate matches; it also preserves all extracted PDF pages as UTF-8 text.
- The latest release only reports approximate thousands. Values match the request's guide figures because those are CBS's published rounded figures, not because chart code contains them.
- annual_total_balance.csv is read directly from spreadsheet cells: ST02-08a H29/H30 and ST02-09a G14. The sheets' headers, units, years and national internal-migration zero are asserted.
- E/4 is independently extracted to israeli_only_balance_audit.csv. Its 16 annual rows reconcile returns minus departures. It never supplies the annual chart's total balance.
- excluded_annual_rows.csv retains unplotted pre-2023 totals. Revised E/4 rows are not a verified total migration backcast. Annual chart coverage is calendar years 2023–2025 only; the separate reporting period appears in the two following component charts. Historical reconstruction is audited in historical_reconstruction_audit.csv.
- reconciliation.csv records both latest-period arithmetic residuals (zero at reported precision). Natural increase is derived from births minus deaths.
- source font files and exact resolved paths are recorded in font_validation.csv. The unchanged assets/brand/pterosaur-simplified.svg supplies the signature.

The population-table HTML and public API index snapshots preserve discovery provenance. The 2026 annual page links to a file inventory containing table 2.9 published October 8, 2026; its historical table 2.8 was not yet available in that inventory. The 2025 inventory contains table 2.8 with 2023–2024 under the post-2023 population methodology. The two vintages use the same post-2023 definitions; no methodological break is inferred from publication date alone. The 2026 table 2.8 direct URL returned HTML instead of a workbook, preserved as st02_08-2026-unavailable.html.

The latest holiday-period population change is for Israelis, excluding the separate foreign population. Annual totals are also from the Israelis' population tables. The difference between post-change population-accounting totals and subsequently revised E/4 flows must not be silently “repaired” by adding series from different definitions or vintages.

To refresh, download the exact URLs in sources.csv to a separate review folder, check revisions and definitions, then deliberately replace the snapshot. Do not silently overwrite the preserved inputs.
