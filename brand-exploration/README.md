# The Data Decoded: local brand study

This development-only comparison is outside Astro and its production artifact. It changes no live page, historical chart, or production R template. All chart values and map regions are **synthetic demonstration data**. Markos Tsinganis appears only in website examples, never on a chart or X application.

## Current defaults after the NYC trial revision

White `#FFFFFF` is the default for future chart canvases, panels, legends, and label backgrounds. Earlier paper-background synthetic exports remain archived exploration; this revision does not regenerate them. Keep dimensions flexible: the NYC monthly and cumulative masters are each 8.8 × 8.8 inches (2112 × 2112 PNG pixels).

**Source:** is mandatory. **Notes:** is optional; omit empty notes. Use bold field labels with regular Work Sans content, align fields with the main content's left margin, use one normal space after each colon, and align continuation lines at the footer left margin. Tighten field spacing; do not use padded columns or hanging indents. Keep metadata smaller than chart labels but readable at the intended size. Include actual snapshot/access dates, and leave detailed definitions and methodology on the project page. Retain the faint divider, then the left-aligned simplified pterosaur and THE DATA DECODED, preserving intrinsic logo proportions and comfortable spacing.

The NYC presentation trial uses solid series, faint solid gridlines, solid annotation leaders, direct endpoint labels, and one PNG/SVG master per chart. Year colors are blue `#2455FF` (2025), crimson `#C83242` (2020), palette B amber `#D49A44` (2021), and palette B teal `#087F79` (2026). The subdued context lines use `#A6B0BD` at 65% opacity and thin strokes; this is a chart-specific choice. The SVG exporter inserts metadata and embedded licensed fonts inside the single SVG root, after its opening tag. No shared production R functions or chart templates are approved or extracted. Visual approval remains pending.

## Preview and exports

From the repository root in PowerShell:

```powershell
python -m http.server 8765 --directory brand-exploration
```

Open <http://localhost:8765/r-prototypes/> for the current Work Sans chart-frame study. The root page at <http://localhost:8765/> retains the earlier symbol, color, and chart trials. <http://localhost:8765/typography/> archives the Work Sans versus Georgia title comparison. Stop the server with Ctrl+C. Current preview fonts are served from `fonts/` locally; no Google Fonts request is needed.

Regenerate the direct R exports from the repository root:

```powershell
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' brand-exploration/r-prototypes/render.R
node brand-exploration/r-prototypes/verify.mjs
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' brand-exploration/r-prototypes/verify.R
```

Use your own Rscript path if R is installed elsewhere. The renderer requires `ggplot2`, `ragg`, `svglite`, `systemfonts`, `jsonlite`, `base64enc`, `rsvg`, and `png`; the R verifier needs `rsvg`, `png`, and `base64enc`. Eight portrait and three landscape synthetic frames each produce a PNG and a self-contained SVG in `r-prototypes/exports/` (1080 × 1920 and 1920 × 1080 respectively). The SVG contains editable chart geometry and text, three embedded Work Sans font files, and a small rasterized rendering of the lightly simplified logo. The logo source remains vector. Embedding the licensed font bytes lets a browser render the SVG without Work Sans installed; other SVG consumers may vary, so use the PNG for fixed appearance. The OFL license accompanies the font files in this repository. `exports/layout.json` records measured text and plot bounds. `simulations/` contains half-resolution diagnostic views of six actual chart PNGs under approximate protanopia, deuteranopia, tritanopia, and grayscale conditions.

The R script registers the pinned TTF files under explicit aliases, checks each file's internal family name, and checks that font matching resolves to those exact paths. A missing file stops export before opening a graphics device; it does not silently substitute Arial. To check the failure path without changing the study, set `TDD_FONT_DIR` to an empty directory when running the script. R can use the bundled TTFs without a Windows-wide installation. For other RStudio scripts that call `family = 'Work Sans'` directly, install the three TTFs with Windows Explorer, restart RStudio, and confirm `systemfonts::match_font('Work Sans')` resolves to Work Sans. Source, pinned version, hashes, license, and Windows instructions are in [fonts/README.md](fonts/README.md).

## Confirmed identity and open choices

- **Approved family:** Work Sans alone. Titles use Bold; optional subtitles and body use Regular; labels and annotations use Regular or Medium; sources and notes use Regular at an intended readable size. Size, weight, and spacing form the hierarchy. Georgia and IBM Plex comparisons are historical exploration, not live options.
- **Confirmed blue:** `#2455FF`. On paper `#F7F5EE`, its measured WCAG contrast is 5.04:1. All three working pterosaur SVGs use this exact flat fill; the R renderer reads the simplified SVG directly without replacing its color.
- **Preferred trial mark:** `pterosaur-simplified.svg`, the lightly simplified interpretation. `pterosaur-compact.svg` remains a 24 px test only, for use where an actual-size test makes its stronger eye and feet necessary. No new logo is approved for production replacement.
- **Preferred warm accent:** crimson `#C83242`. Vermilion `#D94A38` remains in the archived earlier study, outside the current A/B comparison. On paper, their contrast ratios are 4.82:1 and 3.86:1 respectively. The categorical system remains a proposal.
- **Other proposed colors:** ink `#172033`, paper `#F7F5EE`, context slate `#7B8494`, and decorative lime `#D6EE42`. Lime is not a data or small-text color.

The supplied raster, `reference/blue-pterosaur-original.png`, is preserved byte-for-byte (1254 × 1254, SHA-256 `565F2D4A7D7DB62C34948E4EFE89A8931C9C5F0D327AF9F14617844393B07636`). Its sampled central blue is approximately `#0062DF`; that is the **original reference color**, not the approved asset color. The faithful, simplified, and compact working SVGs use **approved `#2455FF`**, with transparent backgrounds, flat fills, clean paths, and padded viewBoxes. Only their fill values changed; geometry and viewBoxes are unchanged. The silhouette retains curved sweeping wings, long beak, backward crest, eye, and feet. Earlier 24/32/48 px avatar and footer tests showed the faithful eye and feet weakening at 24 px; the simplified version is preferred and the compact version is reserved for that small case. ## Data-color system and limits

The frozen proposals are in [palette.json](palette.json). **A, the retained eight-color core**, in order: `#2455FF`, `#078A80`, `#AA6E1E`, `#C83242`, `#7656B4`, `#277A9C`, `#9B5387`, `#577637`. **B, recommended for a real-project trial:** `#2455FF`, `#087F79`, `#D49A44`, `#C83242`, `#6F62B6`, `#61A5C7`, `#4A5E72`, `#86A65D`. B keeps the confirmed blue and preferred crimson, lightens amber/sky/sage, and replaces mauve with dark slate. In the stacked example this reduces the uninterrupted band of similarly heavy mid-tone colors. A/B line and composition exports hold synthetic data, order, wording, frame, and dimensions constant. The page also shows optional 12/16-color extensions with numeric keys; these remain stress tests. Sequential `#F0F4F4` to `#12365B`, diverging `#9B3652` through `#F3F1EB` to `#245578`, and highlight/context roles stay distinct from the categorical choices; intermediate stops are in `palette.json`.

Use dark strokes for thin lines, plus direct labels or distinct dash patterns. Large fills can be lighter when values are labeled and adjacent areas have clear boundaries. Line end labels use ink `#172033` on paper, and line patterns distinguish series when hues converge. The heatmap prints values in every cell and has a quantitative legend; its label colors are selected against the interpolated fill. The ranked bar highlights one value in confirmed blue `#2455FF`; non-highlighted filled bars use **provisional** `#A6B0BD`. The darker `#617087` remains available for thin context lines. Composition labels use whichever of ink or white gives higher measured contrast, targeting at least 4.5:1. A's C2 teal (`4.24:1` with white) and C3 mustard (`4.24:1` with white) fail that target for either text color; both A and B place C2/C3 outside the final bar with leaders so the layouts match. All remaining inside labels in both palettes pass; B's lowest is C2 white at `4.86:1`, though C2 is outside for comparison consistency. The short ranked example uses a one-line synthetic source and brief optional note; the multipanel footer remains a no-truncation multiline stress test. Detailed methodology belongs on a real project's website page.

The exploratory frame measures wrapped Work Sans text on the export device, then allocates plot space between a title/optional subtitle and a footer. Sources and optional notes sit above a faint divider. The unchanged simplified pterosaur and “THE DATA DECODED” form a left-aligned signature below it, aligned with the main content. The separate synthetic-data badge is gone; demonstration sources and notes disclose the synthetic data. Logo width is fixed physically at 0.60 inch and its height follows the SVG viewBox ratio. Plot viewports retain each example's intended aspect ratio, with extra space centered rather than stretching the plot or shrinking text. Source and note lines are 16 pt in the 7.5 × 13.33 in master. **Title rule:** short titles stay at 35 pt portrait / 30 pt landscape. If that wraps to more than two lines, measure one-point steps down to a minimum of 31 pt portrait / 27 pt landscape and stop when a line is saved; otherwise use the minimum and allocate all needed lines. The before/after ranked comparison is 35 pt / three lines versus 31 pt / two lines; subtitle and plot labels keep their sizes. The gallery also includes an absent-subtitle multipanel figure with long notes, an annotated tall ranking, a quantitative-legend heatmap, and a landscape composition. Read small details using the full SVG/PNG; phone-sized previews make dense labels harder to see.

**Footer correction:** The earlier `grid.raster()` placement used normalized width `0.080` and height `0.056`; on a tall canvas those converted to about 0.60 × 0.75 inches, making the approximately 1.356:1 pterosaur about 0.80:1. The renderer now reads the unchanged SVG's `1220 × 900` viewBox, rasterizes at that ratio, and places it at a fixed 0.60-inch width with height calculated from the intrinsic ratio (about 0.443 inches). A fixed physical gap separates the mark from “THE DATA DECODED.” The SVG export also specifies `preserveAspectRatio="xMidYMid meet"`. The JavaScript check compares each SVG's physical logo placement ratio with the source viewBox, allowing 0.005 for rounded SVG coordinates, and checks source/signature alignment and measured plot bounds. The R check compares the visible blue mark's PNG pixel bounds with the source raster, allowing 0.04 for pixel rounding. Both checks cover portrait and landscape exports. Exact footer spacing and wider palette choices remain provisional.

These manual proposals are informed by [ColorBrewer's qualitative, sequential, and diverging guidance](https://colorbrewer2.org/learnmore/schemes.html), [Paul Tol's notes on categorical discrimination](https://sronpersonalpages.nl/~pault/data/colourschemes.pdf), and [Crameri and colleagues on perceptual color maps](https://doi.org/10.1038/s41467-020-19160-7). They are not copied or certified versions of those palettes. The page calculates nearest categorical pairs with Oklab after full-severity protanopia, deuteranopia, tritanopia, and grayscale approximations using the [Machado et al. model](https://pubmed.ncbi.nlm.nih.gov/19834201/). B's nearest standard-display pair is C2/C7 at 10.3 Oklab units versus A's C2/C6 at 7.6. Under simulated protanopia, B's C3/C8 falls to 2.7; under deuteranopia its nearest pair is C3/C8 at 6.4; under tritanopia C1/C2 is 6.0. In grayscale B's C6/C8 is only 0.3. A has C3/C8 at 3.2 under protanopia, C2/C7 at 2.7 under deuteranopia, C2/C6 at 3.1 under tritanopia, and C2/C3 at rounded 0.0 in grayscale. These are diagnostics, not pass/fail accessibility scores. Actual chart simulations show the same risk in context: close color pairs can merge in the composition, and several line hues become similar, while outside labels, segment dividers, direct labels, and line patterns retain identity. The heatmap keeps cell values and its quantitative legend. The earlier root page has separate diagnostics for its **earlier** palette. Human review on a real chart remains necessary; do not call either A or B color-blind safe.
