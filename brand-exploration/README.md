# The Data Decoded: local brand study

This development-only comparison is outside Astro and its production artifact. It changes no live page, historical chart, or production R template. All chart values and map regions are **synthetic demonstration data**. Markos Tsinganis appears only in website examples, never on a chart or X application.

## Preview and exports

From the repository root in PowerShell:

```powershell
python -m http.server 8765 --directory brand-exploration
```

Open <http://localhost:8765/r-prototypes/> for the current Work Sans chart-frame study. The root page at <http://localhost:8765/> retains the earlier symbol, color, and chart trials. <http://localhost:8765/typography/> archives the Work Sans versus Georgia title comparison. Stop the server with Ctrl+C. Current preview fonts are served from `fonts/` locally; no Google Fonts request is needed.

Regenerate the direct R exports from the repository root:

```powershell
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' brand-exploration/r-prototypes/render.R
node brand-exploration/r-prototypes/verify.mjs
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' brand-exploration/r-prototypes/verify.R
```

Use your own Rscript path if R is installed elsewhere. The renderer requires `ggplot2`, `ragg`, `svglite`, `systemfonts`, `jsonlite`, `base64enc`, `rsvg`, and `png`; the R verifier needs `rsvg` and `png`. Seven portrait and three landscape synthetic frames each produce a PNG and a self-contained SVG in `r-prototypes/exports/` (1080 × 1920 and 1920 × 1080 respectively). The SVG contains editable chart geometry and text, three embedded Work Sans font files, and a small rasterized rendering of the lightly simplified logo. The logo source remains vector. Embedding the licensed font bytes lets a browser render the SVG without Work Sans installed; other SVG consumers may vary, so use the PNG for fixed appearance. The OFL license accompanies the font files in this repository. `exports/layout.json` records measured text and plot bounds. `simulations/` contains half-resolution diagnostic views of six actual chart PNGs under approximate protanopia, deuteranopia, tritanopia, and grayscale conditions.

The R script registers the pinned TTF files under explicit aliases, checks each file's internal family name, and checks that font matching resolves to those exact paths. A missing file stops export before opening a graphics device; it does not silently substitute Arial. To check the failure path without changing the study, set `TDD_FONT_DIR` to an empty directory when running the script. R can use the bundled TTFs without a Windows-wide installation. For other RStudio scripts that call `family = 'Work Sans'` directly, install the three TTFs with Windows Explorer, restart RStudio, and confirm `systemfonts::match_font('Work Sans')` resolves to Work Sans. Source, pinned version, hashes, license, and Windows instructions are in [fonts/README.md](fonts/README.md).

## Confirmed identity and open choices

- **Approved family:** Work Sans alone. Titles use Bold; optional subtitles and body use Regular; labels and annotations use Regular or Medium; sources and notes use Regular at an intended readable size. Size, weight, and spacing form the hierarchy. Georgia and IBM Plex comparisons are historical exploration, not live options.
- **Confirmed blue:** `#2455FF`. On paper `#F7F5EE`, its measured WCAG contrast is 5.04:1.
- **Preferred trial mark:** `pterosaur-simplified.svg`, the lightly simplified interpretation. `pterosaur-compact.svg` remains a 24 px test only, for use where an actual-size test makes its stronger eye and feet necessary. No new logo is approved for production replacement.
- **Recommended warm accent for further testing:** crimson `#C83242`; vermilion `#D94A38` remains a direct comparator. On paper, their contrast ratios are 4.82:1 and 3.86:1 respectively. Use ink for chart labels. The categorical system remains a proposal, and neither option is certified for color-vision accessibility.
- **Other proposed colors:** ink `#172033`, paper `#F7F5EE`, context slate `#7B8494`, and decorative lime `#D6EE42`. Lime is not a data or small-text color.

The supplied raster, `reference/blue-pterosaur-original.png`, is preserved byte-for-byte (1254 × 1254, SHA-256 `565F2D4A7D7DB62C34948E4EFE89A8931C9C5F0D327AF9F14617844393B07636`). Its sampled central blue is approximately `#0062DF`; that sample is not a brand specification. The faithful, simplified, and compact SVGs have transparent backgrounds, flat fills, clean paths, and padded viewBoxes. The silhouette retains curved sweeping wings, long beak, backward crest, eye, and feet. Earlier 24/32/48 px avatar and footer tests showed the faithful eye and feet weakening at 24 px; the simplified version is preferred and the compact version is reserved for that small case. The full silhouette fits inside the circular avatar safe area. No raster image is embedded in the logo SVGs.

## Data-color system and limits

The frozen proposal is [palette.json](palette.json). Its recommended eight-color core, in order, is `#2455FF`, `#078A80`, `#AA6E1E`, `#C83242`, `#7656B4`, `#277A9C`, `#9B5387`, `#577637`. The two line exports and two composition exports hold data, wording, geometry, and frame constant while changing only the warm slot to vermilion or crimson. The page also shows 12/16-color extensions with numeric keys. Those extensions are optional stress tests, not a recommendation to identify that many categories by hue alone. Separate proposed scales are sequential `#F0F4F4` to `#12365B` and diverging `#9B3652` through `#F3F1EB` to `#245578`; intermediate stops are frozen in `palette.json`.

Use dark strokes for thin lines, plus direct labels or distinct dash patterns. Large fills can be lighter when values are labeled and adjacent areas have clear boundaries. Use ink `#172033` for text on paper and light fills. The line test uses direct end labels and line patterns; the heatmap prints values in every cell and has a quantitative legend. The ranked bar highlights one value in confirmed blue `#2455FF`; non-highlighted filled bars use **provisional** `#A6B0BD`. The darker `#617087` remains available for thin context lines. This does not change the categorical, sequential, or diverging palettes.

The exploratory frame measures wrapped Work Sans text on the export device, then allocates plot space between a title/optional subtitle and a footer. Sources and optional notes sit above a faint divider. The unchanged simplified pterosaur and “THE DATA DECODED” form a left-aligned signature below it, aligned with the main content. The separate synthetic-data badge is gone; demonstration sources and notes disclose the synthetic data. Logo width is fixed physically at 0.60 inch and its height follows the SVG viewBox ratio. Plot viewports retain each example's intended aspect ratio, with extra space centered rather than stretching the plot or shrinking text. Source and note lines are 16 pt in the 7.5 × 13.33 in master. The long title, absent subtitle, and multiline footer are measured, not positioned for one fixed line count. The gallery includes a four-panel line figure, tall annotated ranking, heatmap with quantitative legend, and landscape stacked composition, alongside the earlier bars and eight-series lines. Read small details using the full SVG/PNG; phone-sized previews make dense labels harder to see.

**Footer correction:** The earlier `grid.raster()` placement used normalized width `0.080` and height `0.056`; on a tall canvas those converted to about 0.60 × 0.75 inches, making the approximately 1.356:1 pterosaur about 0.80:1. The renderer now reads the unchanged SVG's `1220 × 900` viewBox, rasterizes at that ratio, and places it at a fixed 0.60-inch width with height calculated from the intrinsic ratio (about 0.443 inches). A fixed physical gap separates the mark from “THE DATA DECODED.” The SVG export also specifies `preserveAspectRatio="xMidYMid meet"`. The JavaScript check compares each SVG's physical logo placement ratio with the source viewBox, allowing 0.005 for rounded SVG coordinates, and checks source/signature alignment and measured plot bounds. The R check compares the visible blue mark's PNG pixel bounds with the source raster, allowing 0.04 for pixel rounding. Both checks cover portrait and landscape exports. Exact footer spacing and wider palette choices remain provisional.

These manual proposals are informed by [ColorBrewer's qualitative, sequential, and diverging guidance](https://colorbrewer2.org/learnmore/schemes.html), [Paul Tol's notes on categorical discrimination](https://sronpersonalpages.nl/~pault/data/colourschemes.pdf), and [Crameri and colleagues on perceptual color maps](https://doi.org/10.1038/s41467-020-19160-7). They are not copied or certified versions of those palettes. The page calculates nearest categorical pairs with Oklab after full-severity protanopia, deuteranopia, tritanopia, and grayscale approximations using the [Machado et al. model](https://pubmed.ncbi.nlm.nih.gov/19834201/). Standard-display nearest pairs are 02/06 at distance 7.6 for eight categories, 07/12 at 3.4 for twelve, and 12/16 at 1.5 for sixteen. In the eight-color set, vermilion's closest pair under simulated deuteranopia is 03/04 at 2.2, while crimson's is 02/07 at 2.7. Both variants have an eight-color grayscale collision at 02/03 (rounded distance 0.0). These figures flag possible collisions, not accessibility thresholds. Actual chart simulations also show close pairs: in the composition, 02/07 and 03/04 are difficult to tell apart under red-green simulations; several series collapse to similar grays. Segment keys, dividers, direct labels, line patterns, and facets help, but 12–16 categories should use grouping or other cues. The heatmap retains printed values and a quantitative legend in the tritanopia view. The earlier root page has separate diagnostics for its **earlier** categorical set. Human review is still needed before a template. Do not call either palette color-blind safe.

## Archived comparisons and font rights

The [Georgia comparison](typography/index.html) has four 360 × 640 frames: Work Sans throughout versus Georgia Bold in the title, each with a short and a wrapped question. Its old PNG captures freeze the historical rendered appearance. Its SVG sources now refer to local Work Sans files and the viewer's Georgia installation; they remain an archive, separate from the reproducible R exports above. Run `node brand-exploration/typography/generate.mjs` and `node brand-exploration/typography/verify.mjs` to check their sources and dimensions.

[Microsoft's Georgia listing](https://learn.microsoft.com/en-us/typography/font-list/georgia) describes it as a Windows font. [Microsoft's font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq) says Windows font files generally cannot be redistributed, uploaded as webfonts, or converted without additional rights; rendered graphics are a separate use. No Georgia file is in this repository. Work Sans is redistributed under the [SIL Open Font License 1.1](fonts/OFL.txt), with its copyright notice and pinned source recorded next to the TTFs. The earlier IBM Plex and sampled-blue/raspberry trials remain in the root comparison for historical context.

## Remaining decisions

Plot-specific layouts should remain flexible. The live website, historical charts, and X account remain unchanged.
