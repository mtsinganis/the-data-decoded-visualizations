# Project guidance

- The Data Decoded is the primary brand and X identity for Markos Tsinganis's independent visualization collection. Show Markos as the creator with secondary credit on the website only; do not put his name on charts or any X account surface. Lato is the approved default font family for future charts (Black 900 titles, Regular 400 supporting text and footer content, Bold 700 direct year labels and Source/Notes field names) and #2455FF is the confirmed brand blue. The lightly simplified pterosaur is the preferred exploration mark, but no new logo or production chart template has been approved. Prioritize clear questions, sound analysis, source attribution, accessible explanation, and consistent design.
- Read [MIGRATION.md](MIGRATION.md) before migration work; it records decisions and current status.
- Keep one topic per existing `visuals/` folder. Preserve folder names, original inputs, exports, and legacy `index.qmd` during the transition.
- Use R and ggplot2 for analysis and exports. New projects normally use one `analysis.R`, plus `data/`, `plots/`, `story.md`, and `post.md`.
- `story.md` is the single source for website metadata and reader-facing prose. Only `status: published` projects enter Astro; only chart files listed in `charts` may enter its new project pages. The one extra output asset is the old U.S.–Somalia `plots/thumb.svg` direct URL, retained for backward compatibility and checked by the output allowlist. Website builds must not run R.
- GitHub Pages now publishes Astro from `main` through `.github/workflows/deploy-astro.yml` when `ASTRO_PAGES_ENABLED=true`. Keep Quarto's `docs/` and `_quarto.yml` intact as the rollback source; see `MIGRATION.md` for the publishing and rollback steps.

- Future chart defaults: white (`#FFFFFF`) canvas, panels, legends, and label backgrounds; flexible dimensions suited to the chart. A mandatory **Source:** field and useful optional **Notes:** field use bold labels followed by regular Lato content, aligned with the main content left margin. Use one normal space after each colon, compact paragraph wrapping with continuation lines at the footer left margin, and a tight gap between fields; omit empty Notes. Supporting chart text and metadata provisionally use neutral gray `#666666` on white; title uses dark ink. Specific line labels/annotations and connectors match their highlighted line color. Metadata must remain readable at intended size. Put detailed methodology on the project page. Below metadata, retain a faint divider and left-aligned simplified pterosaur followed by THE DATA DECODED, preserving intrinsic logo proportions and spacing.

- Chart title/subtitle spacing: use compact, equal visible gaps between wrapped title lines and between the last title line and the subtitle. Measure rendered line bounds rather than relying on font-size-based leading; the title-line gap must never exceed the title-to-subtitle gap. Apply this convention when creating or revising charts, preserving established Lato weights and inspecting actual exports.

- Across charts with matching canvas dimensions, typography and header line counts, title and subtitle lines must occupy identical relative positions. Use consistent font-metric line slots rather than content-dependent text heights.

- X image ALT text must never exceed 1,000 characters, including spaces and punctuation. Verify each description’s length before delivery; keep story.md and post.md ALT copies synchronized.
